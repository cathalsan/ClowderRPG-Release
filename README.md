# Clowder RPG

Mod para Hytale focado em funcionalidades RPG e Quality-of-Life, com integracao de features experimentais ainda nao oficialmente disponiveis no jogo.

## Download

A versao mais recente esta disponivel na [pagina de Releases](https://github.com/cathalsan/ClowderRPG-Release/releases).

## Instalacao

Colocar o ficheiro `.jar` na pasta de plugins do servidor Hytale.

## Notas

Este repositorio contem apenas as builds publicas do mod. O codigo fonte e privado.
