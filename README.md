# Clowder RPG
A Hytale mod that adds RPG progression on top of the vanilla game: levels,
classes, stats, companions, vocations, teleport tools and a stats menu.
Designed for servers and tunable via configuration.

## Download and installation
Drop the latest `.jar` from the [Releases page](https://github.com/cathalsan/ClowderRPG-Release/releases)
into your server's `mods/` directory and restart. To update, replace the `.jar`.

1. Stop your Hytale server.
2. Drop the `.jar` into the server's `mods/` directory.
3. Start the server — `mods/Clowder_RPG/` is created with all the config files.

To update, replace the `.jar` and restart. Configs regenerate from the JAR
on every boot.

## What's inside
- Player levels, stats and classes
- Combat scaling
- Companions
- Vocations
- Teleport tools
- Custom recipes and shards
- Stats menu (`/menu`)

## Configuration
All configuration lives under `mods/Clowder_RPG/` and is regenerated on every startup by design.
