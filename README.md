# Clowder RPG

A Hytale mod focused on RPG and quality-of-life features, with several experimental systems that aren't part of the base game yet.

## Download

Grab the latest build from the [Releases page](https://github.com/cathalsan/ClowderRPG-Release/releases).

The current version is **v0.3.5**.

## What's inside

- Levelling, stat points and an XP HUD.
- Class system with tiers and passives (Barbarian, Mage, Artificer, etc.).
- Mob difficulty and kill XP scaled to the mob's effective HP, not just its level.
- Crafting recipes for vanilla shards (Silent Henges, Tal'Kesi Refuge) plus a custom shard, **The Call of Y'ha-nthlei**.
- Helipack flight system and 8 crystal-based light source blocks.
- Full teleport suite: `/sethome`, `/home`, `/back`, `/spawn`, public warps and player-to-player teleport requests, all with a configurable warmup, cooldown and combat block.
- Stats GUI with Profile, Stats, Classes, Vocation, Contract Board, Rewards, Leaderboard, Commands, Settings and About tabs.

## Installation

Drop the `.jar` into your Hytale server's `mods/` directory. The mod creates its own `mods/Clowder_RPG/` folder with all configuration files on first startup. Configuration defaults are regenerated from the JAR on every restart, so updating the mod is just a matter of replacing the JAR.

## Notes

This repository only hosts the public builds. The source code is private.
